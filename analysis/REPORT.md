# 서울(강남·송파) → 대전 84㎡ 매매가 시차 분석

**기간**: 2016-09 ~ 2026-08 (약 10년)  
**출처**: App Navi / 국토부 실거래 (전용 84㎡ ±7㎡)  
**가설**: 서울 집값이 먼저 오르고 지방(대전)이 뒤따른다.

## 결론

가설은 **부분 지지**됩니다. 전 기간 월별 수익률은 동행에 가깝지만, **급등 국면에서는 서울이 대전을 약 4~8개월 선행**하는 경향이 있습니다.

| 지표 | 결과 |
| --- | --- |
| 급등 시작점 매칭 시차 (중앙값) | **약 4개월** (구간 0~7개월) |
| 36개월 롤링 최적 시차 (중앙값) | **약 8개월** |
| 가격 TOP5 MoM 교차상관 최적 시차 | **3개월** (corr ≈ 0.53) |
| 유동성 TOP5 바스켓 MoM 교차상관 | **0개월** (corr ≈ 0.18, 약함) |

## 구간별 상승률 (유동성 바스켓)

- **2016~21**: 서울 +119% / 대전 **+181%** (대전이 더 가파름)
- **2022~23**: 서울 −4% / 대전 +3%
- **2024~26**: 서울 **+51%** / 대전 +14% (서울 선행·우위)
